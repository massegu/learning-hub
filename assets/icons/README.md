# Microsoft Fluent Emoji Flat

41 SVG illustrations from [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), licensed under MIT. Vendored from `@iconify-json/fluent-emoji-flat@1.2.6` (Iconify distribution). Original names and SVG bodies are recorded in `fluent-emoji-flat.json`; the license is included in `LICENSE-fluent-emoji.txt`.

`python3 scripts/import-fluent-icons.py` embeds this selected subset into the existing art registry; `python3 scripts/render-stimulus-art.py` creates matching Word PNGs. No CDN, external requests or extra runtime library are needed. Existing Spanish aliases, categories, answer values and special shape/colour/state illustrations stay intact.

## Medallones de áreas

`adventure-areas.png` es una lámina original generada con IA para Learning Hub: ocho medallones ilustrados, fondo transparente, cuadrícula 4 × 2. Libro, brújula, pluma, lupa, puzle, cofre de memoria, rayo y globo. Se conserva como recurso de compatibilidad; las cabeceras actuales usan la lámina con volumen descrita debajo. En ambas, los nombres accesibles siguen siendo texto. No sustituye las categorías ni los estímulos de memoria existentes. Referencia de dirección artística: aventura de bosque y acuarela, sin copiar ilustraciones de Whispering Woods.

## Iconos de áreas con volumen

`learning-areas-3d.png` es una lámina original generada con IA y revisada para esta plataforma: 1448 × 1086 px, 4 columnas × 3 filas. Libro/lápiz, bloques de cálculo, cuaderno, lupa, puzle, cofre, rayo, conversación, globo, geometría, mochila y escucha. Los nombres accesibles siguen siendo texto. Esta lámina sustituye la decoración de las cabeceras y las áreas, sin modificar los 41 pictogramas de respuestas ni sus licencias. El sprite anterior se conserva para compatibilidad.
