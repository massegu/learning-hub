# Cuatro bibliotecas visuales

Comparativa con 16 SVG reales: Lucide (ISC), Tabler (MIT), Phosphor Duotone (MIT) e Iconoir (MIT). Se incluyen las licencias originales, las fuentes y las versiones exactas en `sources.json`. Los ejemplos usan audio, creación, reparación y naturaleza para facilitar la comparación.

Abre `index.html` en un navegador. Se han inspeccionado el trazo, detalle, legibilidad a tamaño grande y licencia; no se afirma que se haya auditado el catálogo completo. Mi candidata para estímulos de adolescentes es Phosphor Duotone. Lucide funciona bien para controles. El usuario ha elegido Phosphor Duotone, aplicado a 74 equivalentes de los estímulos de 13–18 años; los estados específicos mantienen su representación revisada. Son bibliotecas de iconos vectoriales, no de fotografías; las cuatro escenas fotográficas nuevas se generan por separado.
