# Escenas cotidianas variadas

Cuatro escenas base y dos variantes B sintéticas generadas y revisadas el 30/10/2026: cerámica, música, reparación de bicicletas e invernadero. Se conservan los PNG originales sin recortar. Las preguntas revisadas están en `js/photo-library.js`; las cantidades se refieren al primer plano cuando existen objetos secundarios al fondo. No representan personas o establecimientos reales.

Cerámica y música tienen pares revisados de cantidad/presencia/posición; los PNG de bicicletas e invernadero se usan para recuerdo y no tienen una variante B inventada.
